# Media Guide

Editorial guidance for CMS uploads. These are recommendations, not hard crops enforced by the CMS.

## Image formats

- Prefer **AVIF** or **WebP** when exporting from design tools
- Fallback: high-quality **JPEG** or **PNG** for graphics with transparency
- Avoid uploading uncompressed PNGs when JPEG/WebP is sufficient

## Recommended dimensions

| Use                         | Approx. size      | Aspect guidance            |
| --------------------------- | ----------------- | -------------------------- |
| Homepage project cover      | 2400 × 1500px     | Landscape, hotspot enabled |
| Case-study full-width image | 2800 × 1750px     | Landscape or wide preset   |
| Image pair / grid items     | 1600px long edge  | Consistent ratio per block |
| About portrait              | 1200 × 1600px     | Portrait                   |
| OG / social image           | 1200 × 630px      | Fixed social ratio         |
| Video poster                | Match video frame | 16:9 recommended           |

## File size budgets

| Asset            | Target                                                         |
| ---------------- | -------------------------------------------------------------- |
| Cover image      | ≤ 400 KB optimized                                             |
| Case-study image | ≤ 600 KB optimized                                             |
| Portrait         | ≤ 300 KB optimized                                             |
| OG image         | ≤ 250 KB optimized                                             |
| Video file       | ≤ 15 MB for short loops; prefer external hosting for long form |

## Alt text

- Required in both **English** and **Arabic** when an image is used
- Describe content and purpose, not "image of…" decoration
- Portrait alt text should respect privacy preferences

## Video

- Default: **no autoplay**
- Provide poster image and bilingual fallback text
- Use uploaded file for short loops; external URL for hosted reels
- Mute/loop only when editorially necessary

## Hotspots

Hotspots are enabled on cover, portrait, and full-width images. Place the focal point where crops may occur on mobile.

## Cover vs OG image

- **Cover** — homepage card and case-study entry
- **OG image** — social sharing metadata (project-level or site-level)

Keep responsibilities separate; do not reuse one asset for every context unless it works at all sizes.
